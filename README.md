# Web-Scraping

## 📖 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on the FIFA 20 players dataset to uncover player performance trends, market value patterns, positional analysis, and football insights. Using Python and popular data analysis libraries, the project demonstrates data cleaning, visualization, and statistical analysis to generate meaningful insights from football player data.

---

# 🎯 Objectives

- Analyze FIFA player data.
- Perform data cleaning and preprocessing.
- Explore player ratings and potential.
- Identify trends across positions and clubs.
- Visualize important football performance metrics.
- Generate actionable insights from the dataset.

# 🚀 Getting Started

## 1. Clone the Repository

```bash
git clone https://github.com/your-username/fifa-players-data-analysis.git
```

## 2. Navigate to the Project Directory

```bash
cd fifa-players-data-analysis
```

## 3. Install Required Libraries

```bash
pip install -r requirements.txt
```

## 4. Launch Jupyter Notebook

```bash
jupyter notebook
```
